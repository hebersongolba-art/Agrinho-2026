Lunar Engineering (How it works)

The script acts as a Smart Loader in the background: - **Clean Injection:** The script attaches directly to the original Khan Academy page. - **Immediate Activation:** Automation functions start instantly upon clicking. - **Continuous Update:** Since the code is extracted from our cloud, you will always be using the latest version without needing to reinstall.

Starting the System (How to use)

The operation is extremely simple: 1. Go to the **Khan Academy** main page. 2. Click on the bookmark where you saved **MoonScripts**. 3. The system will start silently. 4. Navigate and **open your desired activity**. The script will do the rest. > **System Tip:** Run the script right on the Khan Academy home screen. This way, any activity you open next will already be under the automation effect.

Quick Installation Guide

Choose your platform below and follow the steps to create your activation button:

#### Computer (Chrome / Edge / Brave) 1. Copy the script code at the top of the page. 2. Right-click on your browser's **Bookmarks Bar**. 3. Select **Add page...** 4. In the **Name** field, type: `MoonScripts` 5. In the **URL** field, paste the entire JavaScript code. 6. Click **Save**. #### Android (Google Chrome) 1. Open any website in Chrome. 2. Tap the **Three dots (⋮)** in the top right corner and select **Add to bookmarks**. 3. Go to your **Bookmarks** list. 4. Press and hold the bookmark you just created and tap **Edit**. 5. In the **Name** field, type `MoonScripts`. 6. In the **URL** field, delete the current content and **paste our script**. #### iPhone & iPad (Safari) 1. Open any website in Safari. 2. Tap the **Share** button (the square with an up arrow). 3. Select **Add Bookmark**. 4. Open the **Books icon** (Bookmarks) on the bottom bar. 5. Tap **Edit** and select the created bookmark. 6. Rename it to `MoonScripts` and paste our script into the **URL** field.
